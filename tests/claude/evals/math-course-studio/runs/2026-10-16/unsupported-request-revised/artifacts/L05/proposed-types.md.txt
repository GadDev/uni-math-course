### Prompt (FR)

Pour trois assertions booléennes arbitraires A, B, C, démontrez que les deux règles suivantes ont la même valeur de vérité pour toute affectation : (A ∨ B) ⇒ C et (A ⇒ C) ∧ (B ⇒ C). Rédigez une preuve en texte libre fondée sur leurs cas d’échec ; expliquez pourquoi votre argument couvre aussi le cas où A et B sont toutes deux fausses. Le OU est inclusif.

### Prompt (EN)

For arbitrary Boolean statements A, B, C, prove that the following two rules have the same truth value under every assignment: (A ∨ B) ⇒ C and (A ⇒ C) ∧ (B ⇒ C). Write a free-text proof using their failure cases; explain why your argument also covers the case where A and B are both false. OR is inclusive.

### Optional hint (FR / EN)

FR : Comparez les situations qui rendent chaque règle fausse, plutôt que de prouver séparément chaque cas vrai.

EN: Compare the situations making each rule false, rather than proving each true case separately.

### Worked solution — original project work (FR)

La première règle échoue exactement lorsque C est fausse et qu’au moins une des assertions A, B est vraie. La seconde échoue lorsqu’au moins une de ses deux implications échoue : A vraie avec C fausse, ou B vraie avec C fausse. Ce sont exactement les mêmes situations. Les deux règles sont donc fausses ensemble, et vraies dans toutes les autres affectations. Si A et B sont toutes deux fausses, chaque antécédent est faux ; les deux règles sont vraies, quelle que soit C. Si A et B sont toutes deux vraies, les deux règles ont la valeur de C. L’équivalence porte sur toutes les affectations, pas seulement sur un exemple.

### Worked solution — original project work (EN)

The first rule fails exactly when C is false and at least one of A, B is true. The second fails when at least one of its implications fails: A true with C false, or B true with C false. These are exactly the same situations. Both rules are therefore false together and true in every other assignment. If A and B are both false, every antecedent is false; both rules are true regardless of C. If A and B are both true, both rules have the value of C. The equivalence concerns every assignment, not just one example.
