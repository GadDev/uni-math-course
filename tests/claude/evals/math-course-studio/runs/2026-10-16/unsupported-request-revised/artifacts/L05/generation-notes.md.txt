## Answer-key verification summary

Route A uses the lesson's unique failure condition. Route B uses independent Boolean enumeration via logic-check.mjs for E01–E04 and P01, and a separate dependency-free domain/hidden-face enumeration for E05/E06. Formula strings in answer-checks.json were compared with draft prompts and assumptions. Helper results verify specified formulas; they do not interpret prose or establish pedagogical difficulty.

- E01 key true (option position 2): either completion of B leaves a false antecedent. Both completions were enumerated. Unknown information is not an extra truth value.
- E02 key 00 false, 01 false, 10 true, 11 true: the outer rule fails exactly when A is false. Independently rewrite ¬(¬A ∨ B) ∨ A as (A ∧ ¬B) ∨ A, hence A; helper checks every row.
- E03 key either-complete (position 4): P or R each guarantees Q. Helper checks all eight assignments, both assumptions and all four conclusions; only the selected conclusion is guaranteed. Countermodels in option feedback satisfy the premises.
- E04 key failure (position 1): trigger true and result false. De Morgan gives ¬(¬(A ∨ B) ∨ C), the selected condition; enumeration verifies equivalence and rejects each alternative. Includes both-trigger, single-trigger and no-trigger events.
- E05 key minimal (position 3): a public slip and an unsigned slip can independently hide the sole failure type. Enumeration tests all 16 hidden-face configurations and every candidate inspection set: public+unsigned is uniquely sufficient among offered sets; neither member can be omitted. This establishes minimality, including both signed/private safe faces.
- E06 key exact (position 2): solve n > 2, n ≤ 5, n ≠ 4 to get {3, 5}. Enumeration over 0–12 independently agrees; bounds prove there are no further counterexamples for n > 12. Explicit checks: 0, 2 (false condition), 3, 5 (failures), 4 (exception), 6 (true conclusion).
- P01: the worked solution compares identical failure conditions; all eight assignments independently agree. Both A and B false and both true are explicitly addressed. This supports the model solution, not automatic grading of arbitrary learner text.
