L20 — Rules, permissions and proofs

Method

Only A can S: S ⇒ A. Violation: S ∧ ¬A. A necessary condition does not guarantee permission. To negate a statement, switch quantifiers and apply ¬(P ⇒ Q) ≡ P ∧ ¬Q.

Written practice

1. Translate and negate only administrators can delete a file.

2. Translate and negate every administrator can delete every file.

3. Translate and negate there exists a file nobody can delete.

4. Does an administrator without permission refute the only administrators rule? Justify.
