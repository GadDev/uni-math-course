L19 — Indices, comparaisons et arrêt anticipé

Méthode

Tri : comparer les voisins i et i+1, i dans K. Doublon : chercher i < j de même valeur. Maximum : chercher un indice i dominant tous les j. all sur vide = True ; any sur vide = False.

Entraînement écrit

1. Pour t = [1,3,2], donnez les indices valides de départ, puis les comparaisons exécutées par all.

2. Pour t = [2,2,5,5], donnez une paire témoin de doublon et tous les indices maximaux.

3. Pour t = [], donnez les valeurs de triée, non triée, doublon et contient son maximum.
