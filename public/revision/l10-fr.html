2. Deux tests différents

x ∈ A : x est directement listé. B ⊆ A : chaque élément de B est dans A. Un seul élément manquant réfute l’inclusion.

∅ ⊆ A ; A ⊆ A. ∅ ≠ {0} ; ∅ ≠ {∅}.

3. À vous

Soit C = {2, {3}, ∅}. Justifiez : 3 ∈ C ? {3} ∈ C ? {3} ⊆ C ?

Donnez le plus petit ensemble contenant −5/3, puis 8/4.
