# Équations et inéquations

Résoudre, c’est décrire exactement tous les nombres qui respectent une condition. Imaginez une balance : faire la même opération réversible des deux côtés conserve l’équilibre. Une inéquation demande en plus de conserver l’ordre, ou de l’inverser si l’on multiplie par un négatif.

## Objectifs et prérequis

- Isoler une inconnue.
- Résoudre avec des fractions.
- Inverser correctement une inégalité.
- Écrire un ensemble de solutions.
- Préserver les cas nuls et le domaine.
- Analyser une transformation non équivalente.

Prérequis : L21, L22, L23. Les domaines et restrictions précisés ci-dessous font partie de chaque règle.

**Rappel.** [L22](../L22/) fournit la distributivité ; [L23](../L23/) apprend à garder les dénominateurs non nuls. Une **solution** est une valeur qui rend l’énoncé vrai. On note $S$ l’ensemble de ces valeurs et $\varnothing$ l’ensemble vide. Une borne **stricte** est exclue ; une borne **large** est incluse.

## 1. Comprendre — Trouver toutes les entrées autorisées

Trois tickets identiques et des frais fixes de 5 euros coûtent 11 euros. Quel est le prix d'un ticket ? Si x représente ce prix, l'équation $3x+5=11$ décrit une égalité à satisfaire. Si le budget est de 11 euros au maximum, on obtient plutôt $3x+5\le11$. Dans ce contexte le prix est non négatif ; les exercices du PDF qui suivent sont résolus sur les réels.

Une équation cherche toutes les valeurs qui rendent une égalité vraie ; une inéquation cherche toutes celles qui satisfont un ordre. Le symbole $\Leftrightarrow$ signifie que les deux conditions ont exactement les mêmes solutions sur le domaine annoncé. Tester un candidat ne suffit pas à prouver qu'on a trouvé toutes les solutions.

## 3. Calculer — Une transformation à la fois

**A — Équation : isoler et vérifier (PDF, pages 19–20).**

| Opération | Équation |
| --- | --- |
| Départ | $3x+5=11$ |
| Soustraire 5 aux deux membres | $3x+5-5=11-5$ |
| Réduire | $3x=6$ |
| Diviser les deux membres par 3 | $3x/3=6/3$ |
| Écrire la solution | $x=2,\quad S=\{2\}$ |

Contrôle dans l'équation de départ : $3\cdot2+5=11$. Les transformations sont réversibles : multiplier par 3 puis ajouter 5 permet de revenir au départ. C'est ce qui garantit qu'aucune solution n'a été perdue.

Exemple supplémentaire avec parenthèses : $4(x-1)+2=14\Leftrightarrow4x-2=14\Leftrightarrow4x=16\Leftrightarrow x=4$. Contrôle : $4(4-1)+2=14$.

Pour $ax+b=c$, ne jamais diviser avant d'avoir vérifié a :

| Cas | Résultat |
| --- | --- |
| $a\ne0$ | $S=\{(c-b)/a\}$ |
| $a=0,\ b=c$ | $S=\mathbb R$ |
| $a=0,\ b\ne c$ | $S=\varnothing$ |

Diviser une égalité par une constante négative ne change pas le signe égal.

**B — Ne pas perdre une solution (PDF, page 20).**

Le piège du professeur : $x^2=x$. Diviser par x suppose x non nul et fait disparaître la solution zéro. Factoriser plutôt :

$$x^2=x\Leftrightarrow x^2-x=0\Leftrightarrow x(x-1)=0.$$

$$x=0\quad\lor\quad x=1,\qquad S=\{0,1\}.$$

Les deux candidats vérifient l'équation initiale. Même méthode pour $x^2=3x\Leftrightarrow x(x-3)=0$, $S=\{0,3\}$.

**C — Inéquations : vérifier le signe du diviseur (PDF, pages 21–22).**

Le PDF montre $2<3$ mais $-2>-3$. Multiplier par un négatif inverse l'ordre ; diviser par un négatif revient à multiplier par son inverse négatif.

| Opération | Effet sur l'ordre |
| --- | --- |
| Ajouter ou soustraire la même quantité | Conserver |
| Multiplier ou diviser par un positif | Conserver |
| Multiplier ou diviser par un négatif | Inverser |
| Multiplier par zéro | Perte d'information, pas une équivalence |
| Diviser par zéro | Interdit |

Exemple du professeur :

$$-2x+4>0\Leftrightarrow-2x>-4\Leftrightarrow x<2.$$

La dernière étape divise par −2. La solution est $S=]-\infty;2[$. Testons trois valeurs dans la condition initiale :

| x | $-2x+4$ | Satisfait la condition ? |
| --- | --- | --- |
| 0 | 4 | Oui |
| 2 | 0 | Non : strict |
| 3 | −2 | Non |

<figure class="teaching-figure">
<img src="/diagrams/droites/fr/inequality.svg" alt="Une demi-droite vers la gauche, avec un cercle ouvert en 2, représente x inférieur à 2." width="440" height="360" loading="lazy" />
<figcaption>Le cercle ouvert exclut la borne 2.</figcaption>
</figure>

Les tests aident à repérer une erreur ; l'équivalence justifie la demi-droite entière. Pour une borne incluse, $3x-6\ge0\Leftrightarrow x\ge2$, $S=[2;+\infty[$. Autre exemple : $-4x+3\le11\Leftrightarrow-4x\le8\Leftrightarrow x\ge-2$, $S=[-2;+\infty[$.

| Inégalité | Intervalle | Borne 2 |
| --- | --- | --- |
| $x<2$ | $]-\infty;2[$ | Exclue |
| $x\le2$ | $]-\infty;2]$ | Incluse |
| $x>2$ | $]2;+\infty[$ | Exclue |
| $x\ge2$ | $[2;+\infty[$ | Incluse |

Nous gardons la notation française des intervalles dans les deux langues. Pour un coefficient de signe inconnu, distinguer les cas. Par exemple, pour $ax>2$ :

- $a>0$ : $x>2/a$.
- $a<0$ : $x<2/a$.
- $a=0$ : $0>2$ est faux, donc $S=\varnothing$.

**D — Domaine et candidats supplémentaires (compléments du projet).**

Avant de simplifier $(x^2-4)/(x-2)=4$, écrire $x\ne2$. La factorisation donne $x+2=4$, donc x = 2 serait le seul candidat. Il est exclu, d'où $S=\varnothing$.

Élever au carré peut ajouter des candidats : $x=2\Rightarrow x^2=4$ mais la seconde condition autorise aussi −2. Pour une équation avec racine, noter les restrictions de domaine et de signe avant le carré ; vérifier dans l'original. Le troisième exercice applique cette méthode.

## 5. Pratiquer — Isoler, inverser, vérifier

<div className="algebra-exercise">

### 1. Application

Résoudre $(x+1)/3=2$ dans les réels.

<details>
<summary>Indice</summary>

Le dénominateur est une constante non nulle.

</details>

<details>
<summary>Solution expliquée</summary>

Multiplier par $3$ donne $x+1=6$, puis $x=5$. Donc $S=\{5\}$. Contrôle : $(5+1)/3=2$.

</details>

</div>


<div className="algebra-exercise">

### 2. Enchaînement

Résoudre $-3x+6\ge0$ et tester la borne.

<details>
<summary>Indice</summary>

La division se fait par un nombre négatif.

</details>

<details>
<summary>Solution expliquée</summary>

$-3x\ge-6\Leftrightarrow x\le2$, donc $S=]-\infty;2]$. À $x=2$, le membre gauche vaut zéro : la borne convient.

</details>

</div>


<div className="algebra-exercise">

### 3. Raisonnement

Résoudre $\sqrt{x+2}=x$ dans les réels.

<details>
<summary>Indice</summary>

Le radicande doit être non négatif ; le membre droit doit aussi l’être. Après un carré, vérifiez les candidats.

</details>

<details>
<summary>Solution expliquée</summary>

Il faut $x\ge-2$ et, par le signe de la racine, $x\ge0$. Le carré donne $x+2=x^2$, soit $(x-2)(x+1)=0$. Les candidats sont $2$ et $-1$. Seul $2$ convient : $\sqrt4=2$, tandis que $\sqrt1=1\ne-1$. Donc $S=\{2\}$.

</details>

</div>

**Pratique et bilan**

La banque contient 15 questions originales : 5 faciles, 5 moyennes et 5 difficiles. Commencez sans indice ; après la correction, expliquez pourquoi chaque autre proposition échoue. Les questions difficiles demandent un transfert ou une analyse, pas seulement un calcul plus long. Un indice ou un nouvel essai reste utile pour apprendre, mais ne constitue pas une nouvelle preuve indépendante de maîtrise. Les tentatives sont conservées dans votre progression après connexion.

## 6. Retenir — Fiche de révision à imprimer

<div className="algebra-revision">

- Écrire le domaine, développer ou factoriser, transformer les deux membres, écrire S, vérifier.
- $ax+b=c$ : $x=(c-b)/a$ si $a\ne0$. Si a = 0, comparer b et c.
- Inéquation : positif conserve l'ordre ; négatif inverse l'ordre ; coefficient nul à traiter séparément.
- Borne stricte : cercle vide ; borne large : disque plein. Toujours exclure les infinis.
- Ne pas diviser par l'inconnue sans traiter zéro. Un carré peut ajouter des candidats ; contrôler dans l'original. Les valeurs interdites restent interdites.

**Auto-évaluation.** Refaire l'exemple de la balance, expliquer le retournement de l'ordre, écrire les quatre intervalles puis justifier pourquoi un candidat peut être rejeté.

**Pour imprimer:** utilisez la commande Imprimer du navigateur. Les ateliers montrent un exemple fixe ; indices et solutions sont développés sur papier.
