# Equations and inequalities

Solving means describing exactly all numbers satisfying a condition. Imagine a balance: the same reversible operation on both sides preserves balance. An inequality also requires preserving order, or reversing it when multiplying by a negative number.

## Objectives and prerequisites

- Isolate an unknown.
- Solve with fractions.
- Reverse an inequality correctly.
- Write a solution set.
- Preserve zero cases and domains.
- Analyse a nonequivalent transformation.

Prerequisites: L21, L22, L23. Domains and restrictions stated below are part of every rule.

**Reminder.** [L22](../L22/) provides distributivity; [L23](../L23/) teaches nonzero denominator restrictions. A **solution** is a value making the statement true. Write $S$ for the set of those values and $\varnothing$ for the empty set. A **strict** boundary is excluded; an **inclusive** boundary is included.

## 1. Understand — Find every allowed input

Three identical tickets and a fixed fee of 5 euros cost 11 euros. What does one ticket cost? If x is the price, equation $3x+5=11$ describes an equality to satisfy. If the budget is at most 11 euros, we instead get $3x+5\le11$. In this context the price is nonnegative; the following PDF exercises are solved over the reals.

An equation asks for every value making equality true; an inequality asks for every value satisfying an order. Symbol $\Leftrightarrow$ means both conditions have exactly the same solutions on the stated domain. Testing one candidate does not prove that all solutions have been found.

## 3. Calculate — One transformation at a time

**A — Equation: isolate and check (PDF, pages 19–20).**

| Operation | Equation |
| --- | --- |
| Start | $3x+5=11$ |
| Subtract 5 from both sides | $3x+5-5=11-5$ |
| Simplify | $3x=6$ |
| Divide both sides by 3 | $3x/3=6/3$ |
| Write the solution | $x=2,\quad S=\{2\}$ |

Check in the original equation: $3\cdot2+5=11$. The transformations are reversible: multiply by 3 then add 5 to return to the start. That ensures no solution has been lost.

Additional example with parentheses: $4(x-1)+2=14\Leftrightarrow4x-2=14\Leftrightarrow4x=16\Leftrightarrow x=4$. Check: $4(4-1)+2=14$.

For $ax+b=c$, never divide before checking a:

| Case | Result |
| --- | --- |
| $a\ne0$ | $S=\{(c-b)/a\}$ |
| $a=0,\ b=c$ | $S=\mathbb R$ |
| $a=0,\ b\ne c$ | $S=\varnothing$ |

Dividing an equality by a negative constant does not change the equals sign.

**B — Do not lose a solution (PDF, page 20).**

The professor's trap: $x^2=x$. Dividing by x assumes x is nonzero and loses the zero solution. Factorise instead:

$$x^2=x\Leftrightarrow x^2-x=0\Leftrightarrow x(x-1)=0.$$

$$x=0\quad\lor\quad x=1,\qquad S=\{0,1\}.$$

Both candidates satisfy the original equation. Use the same method for $x^2=3x\Leftrightarrow x(x-3)=0$, $S=\{0,3\}$.

**C — Inequalities: check the divisor sign (PDF, pages 21–22).**

The PDF shows $2<3$ but $-2>-3$. Multiplying by a negative reverses order; dividing by a negative amounts to multiplying by its negative reciprocal.

| Operation | Effect on order |
| --- | --- |
| Add or subtract the same amount | Preserve |
| Multiply or divide by a positive | Preserve |
| Multiply or divide by a negative | Reverse |
| Multiply by zero | Information lost, not an equivalence |
| Divide by zero | Undefined |

Professor's example:

$$-2x+4>0\Leftrightarrow-2x>-4\Leftrightarrow x<2.$$

The last step divides by −2. The solution is $S=]-\infty;2[$. Test three values in the original condition:

| x | $-2x+4$ | Satisfies the condition? |
| --- | --- | --- |
| 0 | 4 | Yes |
| 2 | 0 | No: strict |
| 3 | −2 | No |

<figcaption>The open circle excludes endpoint 2.</figcaption>

Tests help catch errors; equivalence justifies the whole ray. For an included boundary, $3x-6\ge0\Leftrightarrow x\ge2$, $S=[2;+\infty[$. Another example: $-4x+3\le11\Leftrightarrow-4x\le8\Leftrightarrow x\ge-2$, $S=[-2;+\infty[$.

| Inequality | Interval | Boundary 2 |
| --- | --- | --- |
| $x<2$ | $]-\infty;2[$ | Excluded |
| $x\le2$ | $]-\infty;2]$ | Included |
| $x>2$ | $]2;+\infty[$ | Excluded |
| $x\ge2$ | $[2;+\infty[$ | Included |

We retain French interval notation in both languages. For a coefficient of unknown sign, split cases. For example, for $ax>2$ :

- $a>0$ : $x>2/a$.
- $a<0$ : $x<2/a$.
- $a=0$ : $0>2$ is false, so $S=\varnothing$.

**D — Domain and extra candidates (project extensions).**

Before simplifying $(x^2-4)/(x-2)=4$, write $x\ne2$. Factorisation gives $x+2=4$, so x = 2 would be the only candidate. It is excluded, hence $S=\varnothing$.

Squaring can introduce candidates: $x=2\Rightarrow x^2=4$ but the second condition also allows −2. For a root equation, state domain and sign restrictions before squaring; check in the original. The third exercise applies this method.

## 5. Practise — Isolate, reverse, check

<div className="algebra-exercise">

### 1. Apply

Solve $(x+1)/3=2$ over the reals.

<details>
<summary>Hint</summary>

The denominator is a nonzero constant.

</details>

<details>
<summary>Explained solution</summary>

Multiplying by $3$ gives $x+1=6$, then $x=5$. Thus $S=\{5\}$. Check: $(5+1)/3=2$.

</details>

</div>


<div className="algebra-exercise">

### 2. Combine

Solve $-3x+6\ge0$ and test the boundary.

<details>
<summary>Hint</summary>

Division is by a negative number.

</details>

<details>
<summary>Explained solution</summary>

$-3x\ge-6\Leftrightarrow x\le2$, so $S=]-\infty;2]$. At $x=2$, the left side is zero: the boundary satisfies the condition.

</details>

</div>


<div className="algebra-exercise">

### 3. Reason

Solve $\sqrt{x+2}=x$ over the reals.

<details>
<summary>Hint</summary>

The radicand must be nonnegative; so must the right side. After squaring, check the candidates.

</details>

<details>
<summary>Explained solution</summary>

We require $x\ge-2$ and, from the root’s sign, $x\ge0$. Squaring gives $x+2=x^2$, or $(x-2)(x+1)=0$. Candidates are $2$ and $-1$. Only $2$ works: $\sqrt4=2$, whereas $\sqrt1=1\ne-1$. Thus $S=\{2\}$.

</details>

</div>

## 6. Remember — Printable revision sheet

<div className="algebra-revision">

- Write the domain, expand or factorise, transform both sides, write S, check.
- $ax+b=c$ : $x=(c-b)/a$ if $a\ne0$. If a = 0, compare b and c.
- Inequality: positive preserves order; negative reverses order; handle zero coefficient separately.
- Strict boundary: open circle; inclusive boundary: filled disk. Always exclude infinity.
- Do not divide by the unknown without handling zero. Squaring may add candidates; check in the original. Forbidden values stay forbidden.

**Self-check.** Redo the balance example, explain order reversal, write the four intervals, then justify why a candidate can be rejected.
