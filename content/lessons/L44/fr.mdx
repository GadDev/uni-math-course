# Alphabets et codage par substitution


<span id="pdf-5" class="source-topic-marker"></span>

## Objectifs et prérequis

Vous saurez : (1) reconnaître alphabet source et alphabet cible ; (2) interpréter $S^*$ ; (3) définir $c:S\to T^*$ ; (4) distinguer symbole et mot code ; (5) coder une suite par concaténation ; (6) vérifier un codage avec un exemple.

Prérequis : [L43](/fr/lessons/L43/), ensembles et fonctions. La longueur d'un mot $w$ se note $|w|$.

## Partir d’une question

Coder par substitution ressemble à remplacer chaque lettre par une petite étiquette. La difficulté n’est pas de coller les étiquettes ; elle est de savoir où les séparer à l’arrivée. Rappelez-vous [L43](/fr/lessons/L43/) : le destinataire doit connaître la même convention.

## 01 · Deux alphabets

**PDF, pp. 5 et 7.** On choisit un alphabet source $S$ et un alphabet cible $T$. Le plus souvent dans ce chapitre, $T=\{0,1\}$. L'ensemble $S^*$ désigne toutes les suites finies formées avec les symboles de $S$, y compris le mot vide $\varepsilon$. De même, $T^*$ contient les mots sur $T$.

Le symbole $x$ est un élément de $S$ ; le mot $xyx$ est un élément de $S^*$. Le mot binaire $011$ est un élément de $T^*$ si $T=\{0,1\}$.

**Définition du PDF.** Un codage par substitution est une fonction

$$c:S\longrightarrow T^*.$$

Il associe un mot code $c(s)$ à chaque symbole source $s$. Dans les exemples, les mots codes sont non vides.

## 02 · Étendre le codage aux messages

La même lettre $c$ est utilisée pour coder des mots entiers : on **concatène** les mots codes, sans ajouter automatiquement de séparateur :

$$c(s_1s_2\cdots s_\ell)=c(s_1)c(s_2)\cdots c(s_\ell).$$

**Exemple du PDF, p. 8.** $S=\{x,y,z\}$, $T=\{0,1\}$ et

$$c(x)=0,\qquad c(y)=01,\qquad c(z)=011.$$

Pour $w=xyzx$, on applique la règle symbole par symbole :

| Étape | Symbole | Mot code | Message construit |
| --- | --- | --- | --- |
| 1 | $x$ | $0$ | $0$ |
| 2 | $y$ | $01$ | $001$ |
| 3 | $z$ | $011$ | $001011$ |
| 4 | $x$ | $0$ | $0010110$ |

Donc $c(xyzx)=0010110$.

**Attention.** Les espaces entre mots codes dans un calcul servent à expliquer la méthode. Ils ne sont pas transmis, sauf si le protocole définit un séparateur.

## Comment s’en servir ?

**Quand l’utiliser ?** Quand une table donne un mot code pour chaque symbole et qu’on souhaite transmettre un message fini.

**Lire la notation.** L’étoile de $S^*$ n’est ni une multiplication ni un symbole de l’alphabet : elle indique l’ensemble de tous les mots finis, y compris $\varepsilon$. L’entier $\ell$ dans $s_1\cdots s_\ell$ compte les symboles du message ; il peut différer du nombre de symboles distincts de l’alphabet.

**Comment procéder ?** Vérifiez que chaque symbole du message appartient à $S$. Écrivez son mot code, gardez l’ordre, puis concaténez. Définissez aussi $c(\varepsilon)=\varepsilon$. En séparant mentalement les blocs, on obtient :

$$|c(s_1\cdots s_\ell)|=\sum_{j=1}^{\ell}|c(s_j)|.$$

Chaque bloc apporte autant de bits que sa longueur ; les séparateurs de calcul n’en apportent aucun. Pour le code $c_2$ de l’exemple, $c(yxx)=01\,0\,0=0100$ et $|c(yxx)|=2+1+1=4$. Cela code correctement le message ; la possibilité de retrouver tout message exige une vérification supplémentaire en [L45](/fr/lessons/L45/).

**À vous de jouer.** Avec la même table, encodez $zyx$ et donnez les deux longueurs : avant et après codage.

## Expérimenter et expliquer

**But de l’expérience.** Suivre une substitution et distinguer longueur source et longueur codée.

**Avant de manipuler.** Avec c2, quatre symboles de xyzx donneront-ils quatre bits ?

**Mode d’emploi.** Saisissez un mot sur x, y, z ; les espaces sont refusés car ils ne font pas partie de cet alphabet. Suivez les lignes de la table, une par symbole. Gardez xyzx et changez la table de c2 à d : seuls les mots codes changent, pas le message source. Le bouton ε permet de tester un message vide.

## 03 · Comparer un symbole et un mot

**Exemple pédagogique complémentaire.** Si $a\in S$, alors $c(a)$ est un mot sur $T$, pas nécessairement un seul bit. Pour le code précédent, $|c(x)|=1$, $|c(y)|=2$ et $|c(z)|=3$.

Si le message est $xy$, sa longueur codée vaut $|c(xy)|=1+2=3$. Compter les **symboles source** ($2$) ne donne pas le nombre de **bits transmis** ($3$).

## 04 · Comment savoir décoder ?

Le fait qu'une fonction $c:S\to T^*$ soit correctement définie ne garantit pas encore que tout message codé pourra être retrouvé de façon unique. Par exemple, avec $c(x)=0$, $c(y)=1$ et $c(z)=10$ (PDF, p. 9), le mot $10$ peut représenter $z$ ou $yx$.

Cette question — l'**ambiguïté de décodage** — est traitée dans [L45](/fr/lessons/L45/). Ne confondez pas « c'est une fonction » et « on retrouve l'entrée sans hésitation ».

## Vérifiez vos acquis — solutions incluses

1. **Question.** Le mot $xy$ appartient-il à $S$ ou à $S^*$ ? **Réponse.** À $S^*$ ; $S$ contient les symboles individuels.
2. **Question.** Pour le code du PDF, calculer $c(zz)$. **Réponse.** $011011$.
3. **Question.** Quelle est la longueur de $c(yxx)$ ? **Réponse.** $2+1+1=4$ bits.
4. **Question.** Quelle différence entre $c(x)$ et $c(xy)$ ? **Réponse.** Le premier code un symbole, le second un mot de deux symboles par concaténation.

**Suite.** [L45](/fr/lessons/L45/) : retrouver un message sans ambiguïté.

## À retenir

<div className="info-memo">

- $S$ contient les symboles ; $S^*$ contient les messages finis ; $T^*$ contient les mots codés.
- Une table définit $c:S\to T^*$ ; on l’étend par concaténation et $c(\varepsilon)=\varepsilon$.
- Les longueurs des blocs s’additionnent ; aucun séparateur n’est implicite.
- **Checklist :** alphabet respecté ? ordre conservé ? bits et symboles distingués ? décodage vérifié séparément ?

</div>
