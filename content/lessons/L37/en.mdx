# Functions, domains and graphs

*Original course explanations based on* Bruno Teheux, Mathématiques Générales — Fonctions d’une variable réelle, BINFO-FCE 2025–2026, pages 2, 3, 4. The diagrams and activities below are original project additions.

## Goals and prerequisites

A function connects an **input** to an **output**. In this lesson, you will learn to check whether an input is allowed, calculate its output and plot the corresponding point.

Before starting, check these three skills:

- Evaluate a power of a negative number: $(-1)^3=-1$.
- Recognise that division by zero is undefined.
- Read a point $(2,15)$: first 2 along the horizontal axis, then 15 along the vertical axis.

<p>Need a reminder? See <a href="/en/lessons/L23/">L23 — fractions and powers</a> and <a href="/en/lessons/L27/">L27 — coordinate systems</a>.</p>

## What is a function?

Imagine a calculation box: choose an allowed input, the box applies a rule and returns **exactly one output**. The same input always gives the same output.

The set of allowed inputs is called the **domain** of the function; we denote it by $A$. Here, inputs and outputs are real numbers. The set of all real numbers is written $\mathbb R$.

We can now write:

$$f:A\longrightarrow\mathbb R,\qquad x\longmapsto f(x)$$

- $f$ names the function; $x$ is an input belonging to $A$.
- $f(x)$ is read “f of x” and denotes the output, called the **image of x under f**. It is not multiplication.
- The first arrow gives the domain $A$ and codomain $\mathbb R$. The second shows what an input $x$ becomes.
- Writing $\mathbb R$ as the codomain does not mean every real number is actually obtained.

Different inputs may have the same image. For example, for the square function $g(x)=x^2$ defined on $A=\{-1,0,1\}$, the braces list the three allowed inputs and we have $g(-1)=g(1)=1$. However, one input cannot have two distinct images.

Our main example will be:

$$f(x)=x^3+2x+3,\qquad A=\mathbb R$$

This is a **polynomial** function: its expression uses only sums and products of nonnegative integer powers of $x$. Here, no real input is forbidden. For example, input 2 gives output 15; we will work through that calculation.

## The domain matters

Before calculating an image, ask: “Am I allowed to use this input?” A domain may be specified in the problem. If only a formula is given and its **natural real domain** is requested, find all real inputs for which that formula makes sense.

Consider a **rational** function, meaning a quotient of polynomials:

$$r(x)=\frac{x^2-2x+2}{x(x-2)}$$

The denominator must not be zero. Work step by step:

1. Identify the denominator: $x(x-2)$.
2. A product is zero if and only if at least one of its factors is zero.
3. Solve for each factor:

$$x(x-2)=0\quad\Longleftrightarrow\quad x\in\{0,2\}$$

Here, $\Longleftrightarrow$ reads “if and only if”; $\in$ means “belongs to”. The set $\{0,2\}$ contains exactly 0 and 2.

4. Exclude these two inputs. There are no other restrictions in this formula.

$$D_r=\mathbb R\setminus\{0,2\}$$

$D_r$ denotes the domain of $r$. The symbol $\setminus$ means “without”: read “all real numbers except 0 and 2”. The value 1 is therefore allowed and gives $r(1)=-1$.

<FunctionPanel kind="domain" locale="en" client:visible />

The natural domain depends on the formula: for a real square root, the expression under the root must be nonnegative. Here, we mainly work with polynomials and their quotients.

## Worked example: evaluating a function

Return to $f(x)=x^3+2x+3$. Its domain is $\mathbb R$: all three inputs below are allowed.

To calculate $f(2)$:

1. Replace **every** $x$ with 2, including the one in $2x$.
2. Evaluate the power, then the product, then the sum:

$$f(2)=2^3+2\times2+3=8+4+3=15$$

For a negative input, parentheses keep the sign with the number:

$$f(-1)=(-1)^3+2\times(-1)+3=-1-2+3=0$$

Finally:

$$f(0)=0^3+2\times0+3=3$$

In $f(2)=15$, **2 is the input and 15 is its image**. Asking for “the image of 2” means asking for the value of $f(2)$. The table and slider in the next section connect these calculations to their points.

## From formulas to graphs

For every allowed input $x$, take the point $(x,f(x))$. The first coordinate is the input (**abscissa**, horizontal axis); the second is its image (**ordinate**, vertical axis).

For example, $f(2)=15$ gives the point $(2,15)$. To plot it, locate 2 on the horizontal axis, then move up to height 15. Similarly:

$$f(0)=3\quad\Longleftrightarrow\quad (0,3)\in G_f$$

$G_f$ denotes the **graph** of $f$, and $\in$ means “belongs to”. The double arrow reads “if and only if”: the calculation and point membership say the same thing.

<FunctionPanel kind="graph" locale="en" client:visible />

A few points provide reference values, but are not the entire graph. For domain $A=\mathbb R$, the graph contains a point for **every** real input, including between table values and beyond the displayed window.

We write this idea as:

$$G_f=\{(x,f(x))\mid x\in A\}\subseteq\mathbb R^2$$

Braces denote a set; the bar $\mid$ reads “such that”; $\subseteq$ means “is a subset of”. Finally, $\mathbb R^2$ is the set of pairs of real numbers, represented in the plane. The formula therefore says: “the graph collects every input–image pair, for inputs in the domain”.

**Vertical line test.** A vertical line fixes a horizontal coordinate. If it meets a drawing at two points, that input would have two images: the drawing is not the graph of a function of x. A vertical line may meet no points when its horizontal coordinate is outside the domain.

## Two common traps

**1. Simplifying without preserving the original domain.** Consider:

$$h(x)=\frac{x(x-2)}{x-2},\qquad D_h=\mathbb R\setminus\{2\}$$

For $x\ne2$ (“x different from 2”), we can simplify to $h(x)=x$. However, the original expression still requires $x\ne2$: simplification does not define $h(2)$. Assigning the value 2 at that input afterwards would give a **different function**, with a larger domain.

**2. Reversing input and image.** The point $(2,15)$ tells us $f(2)=15$; it does not say $f(15)=2$. Coordinate order matters.

For this lesson’s rational function, the exclusions remain:

$$0\notin D_r,\qquad 2\notin D_r$$

The symbol $\notin$ means “does not belong to”: neither $r(0)$ nor $r(2)$ is defined. Division by zero does not provide an image equal to infinity.
