# Assertions: statements with one truth value

## Your objective

By the end of this lesson, you can decide whether a sentence is an assertion, fix its context, and write its truth value as $1$ or $0$.

**Prerequisites:** the ability to read simple statements in French or English. No earlier lesson is required.

## What is an assertion?

An **assertion** is a statement that is either true or false. Classical propositional logic (LPC in the course) studies these objects because they are the building blocks of valid reasoning.

- “Two is an even number.” This is an assertion, and it is true.
- “Ten is a prime number.” This is an assertion, and it is false.

You do not need to know the value to recognise an assertion. You need to know that exactly one of the two values applies.

## Sentences that are not assertions

Three common kinds of sentence are not assertions.

- **Questions and commands:** “What time is it?” and “Close the window.” are neither true nor false.
- **Vague sentences:** “It is hot.” depends on an unstated threshold, place and time. Different listeners may give different answers.
- **Self-referential sentences:** “This sentence is false.” is discussed in the trap below.

Opinions such as “This lesson is beautiful.” are also not assertions in this course, because their truth value depends on taste.

## Context and notation

In the course’s classical setting, a precise, non-paradoxical declarative statement has exactly one truth value once its meaning and all relevant context are fixed, even if we do not know that value. Fixing only the speaker, place and time does not turn a question, a vague sentence or the liar sentence into an assertion. The sentence “It rains in Luxembourg City on 14 October 2026 at noon.” is therefore an assertion: it is either true or false.

We name assertions with letters: $A$, $B$, $C$, and so on. We write the truth values as $1$ for true and $0$ for false. If $A$ is “Two is an even number.”, then $A = 1$.

## Guided example: from a vague sentence to an assertion

Start with “It is hot.”

1. Ask what “hot” means: 20 °C? 25 °C? 30 °C?
2. Fix the place and time: Luxembourg City, 14 October 2026, 14:00.
3. Fix the threshold: more than $25$ °C.
4. The result is now a single assertion: “It is more than 25 °C in Luxembourg City on 14 October 2026 at 14:00.” We can check it with a thermometer, even if we have not yet.

This guided work, whose solution is visible, is not an independent response for mastery evidence.

## Trap: the liar sentence

Consider “This sentence is false.”

- If it is true, then what it says holds, so it is false. Contradiction.
- If it is false, then what it says fails, so it is true. Contradiction.

No single value can be assigned consistently. So this sentence is not an assertion in the course’s sense.

A second trap: not knowing a value does not mean there is no value. An assertion can be unknown to us and still be true or false.

## Takeaway

An assertion is a statement with exactly one truth value once its context is fixed. Fix the context, write the assertion with a letter, and then decide its value: $1$ or $0$.
