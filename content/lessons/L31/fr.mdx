# Demi-plans et triangles

Une équation sélectionne un bord ; une inégalité sélectionne un côté. Trois contraintes bien choisies peuvent ensuite remplir un triangle. Revoyez le test d’appartenance ([L28](../L28/)) et les intersections ([L30](../L30/)) ; vous devez aussi savoir qu’une multiplication par un nombre négatif inverse une inégalité.

## Objectifs et prérequis

- Tester une inégalité de demi-plan.
- Distinguer bord inclus et exclu.
- Choisir un côté par un point test.
- Combiner plusieurs contraintes.
- Tester l’intérieur d’un triangle.
- Analyser signe et dégénérescence.

Prérequis : L24, L28, L30. Les domaines et restrictions précisés ci-dessous font partie de chaque règle.

## Les deux demi-plans : tester de quel côté se trouve un point

Une droite coupe le plan en deux régions. **Exemple du PDF, page 50 :** la frontière est $y=2x+1$. Pour $(0,3)$, comparer $3$ à $2\cdot0+1=1$ donne $3>1$ : le point est au-dessus. Pour $(2,0)$, $0<2\cdot2+1=5$ : le point est en dessous.

La différence $f(x,y)=y-2x-1$ vaut respectivement $2$ et $-5$. Son signe suffit donc à distinguer les côtés. Une inégalité stricte exclut la frontière, dessinée en pointillés ; une inégalité large l’inclut, avec un trait continu. Pour une droite verticale, parler plutôt de gauche et de droite.

## Une droite sépare le plan

Pour $f(x,y)=ax+by-c$ avec $(a,b)\ne(0,0)$, la frontière est $f=0$. Les deux demi-plans ouverts sont $f>0$ et $f<0$ ; les versions fermées incluent le bord. Le signe est constant d’un côté de la droite. Il n’est pas toujours pertinent de dire « au-dessus » : une verticale sépare gauche et droite.

## Pourquoi le signe choisit-il un côté ?

Considérons $f(x,y)=ax+by-c$, avec $(a,b)\ne(0,0)$. L’écriture $f(P)$ signifie qu’on remplace les coordonnées par celles du point $P$. La droite est l’ensemble où le résultat vaut zéro.

Si deux points $P$ et $Q$ donnent des signes opposés, les valeurs de $f$ sur le segment qui les relie passent de l’un à l’autre sans saut : elles prennent donc la valeur zéro. Le segment traverse la frontière. Si les deux valeurs sont strictement positives, leurs moyennes pondérées restent positives : le segment reste de ce côté. C’est la raison géométrique du test par signe.

**Comment dessiner une inégalité ?** Tracez sa frontière, choisissez un point hors de cette droite, puis substituez ses coordonnées. Une inégalité vraie retient son côté ; une inégalité fausse retient l’autre. Terminez en décidant si le bord est inclus.

Pour $x+2y\le6$, utilisez $f=x+2y-6$. L’origine donne $f(0,0)=-6<0$ : on garde le côté négatif et le bord. Pour $f(R)\ne0$, le produit $f(P)f(R)$ est positif si les signes sont identiques, négatif s’ils sont opposés et nul si $P$ est sur le bord. Cela explique le test de même côté donné plus bas.

## Exemple guidé : point test

Pour $x+2y\le6$, l’origine donne $0\le6$ : on retient le côté contenant l’origine et la frontière. Le point $(4,2)$ donne $8>6$ et est exclu. Un point de la frontière ne permet pas de choisir le côté, puisque sa valeur est zéro pour les deux inégalités larges.

## Remplir un triangle : combiner trois tests

**Complément du projet, hors du PDF révisé.** Un triangle non aplati est l’intersection de trois demi-plans : pour chaque côté, garder celui qui contient le sommet opposé. Cela transforme un dessin en trois tests algébriques.

Prenons $A=(0,0)$, $B=(4,0)$ et $C=(0,3)$. Les côtés horizontaux et verticaux donnent $y\ge0$ et $x\ge0$. Le troisième côté vérifie $3x+4y=12$, car il passe par $B$ et $C$. L’origine donne $0\le12$ : garder $3x+4y\le12$.

Le point $(1,1)$ satisfait les trois conditions, tandis que $(3,2)$ échoue au troisième test car $3\cdot3+4\cdot2=17>12$. Le bord est inclus ici. Pour remplir une image, tester le centre de chaque pixel ; ce sont les mêmes idées de demi-plan, appliquées à une grille.

## Intersection de contraintes

La région $x\ge0$, $y\ge0$, $x+y\le4$ est un triangle fermé. Un point appartient à la région seulement s’il satisfait les trois tests. Vérifier une seule contrainte ne suffit pas. Les sommets sont $(0,0)$, $(4,0)$ et $(0,4)$ ; les arêtes sont incluses.

## Exemple guidé : triangle général

Pour trois sommets non alignés, chaque côté définit une droite. Pour chaque droite, garder le demi-plan fermé contenant le troisième sommet. Leur intersection est exactement le triangle rempli, bord compris.

Construisez maintenant votre propre triangle. Pour chaque côté, comparez le signe obtenu au sommet opposé et au point testé. Inverser deux sommets change les signes utilisés, mais pas la région ; des sommets alignés imposent d’arrêter le remplissage.

## Un test de même côté

Si $R$ est un point de référence hors de la droite, $P$ est du même côté ou sur le bord lorsque $f(P)f(R)\ge0$. Pour le même côté strict, utiliser $>0$. Multiplier une équation de frontière par un nombre négatif conserve la droite mais inverse les signes. Trois sommets alignés ne définissent pas un triangle d’intérieur non vide ; le test doit signaler ce cas avant le remplissage.

## À vous de jouer sur papier

Le point $(2,2)$ est-il dans $x+2y<6$ ? Et dans $x+2y\le6$ ? Le point $(3,2)$ appartient-il au triangle de sommets $(0,0),(4,0),(0,3)$ ?

<details>
<summary>Afficher la correction expliquée</summary>

Pour $(2,2)$, $x+2y=6$ : le point est exclu du demi-plan ouvert et inclus dans le demi-plan fermé. Pour $(3,2)$, les contraintes $x\ge0$ et $y\ge0$ sont vraies, mais $3x+4y=17>12$ : le point est hors du triangle. Deux tests réussis sur trois ne suffisent pas.

## Fiche de révision à imprimer

- **Frontière :** $ax+by-c=0$, avec $(a,b)\ne(0,0)$ ; le signe choisit un côté.
- **Bord :** $<$ ou $>$ l’exclut ; $\le$ ou $\ge$ l’inclut.
- **Triangle :** choisir pour chaque côté le demi-plan contenant le sommet opposé ; vérifier les trois contraintes.
- **Pièges :** prendre un point test sur la droite ; oublier d’inverser le sens en multipliant par un négatif ; accepter trois sommets alignés comme un triangle d’intérieur non vide.

</section>
