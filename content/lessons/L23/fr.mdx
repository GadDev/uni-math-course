# Fractions, puissances et racines

Simplifier, c’est alléger une écriture sans changer ce qu’elle signifie. Avant d’actionner la « machine à calculer », il faut vérifier si l’entrée est autorisée. Nous séparons trois gestes : additionner des parts, répéter des facteurs et retrouver une racine.

## Objectifs et prérequis

- Additionner des fractions.
- Multiplier et diviser.
- Utiliser les puissances.
- Calculer une racine réelle.
- Conserver le domaine.
- Analyser une simplification.

Prérequis : L21, L22. Les domaines et restrictions précisés ci-dessous font partie de chaque règle.

**Rappel de [L21](../L21/) et [L22](../L22/).** Un facteur est multiplié, un terme est ajouté. On peut simplifier $2x/(2y)$ en $x/y$ si $y\ne0$ ; on ne supprime pas le $2$ dans $(x+2)/(y+2)$. Le **domaine** est l’ensemble des valeurs pour lesquelles tous les calculs sont définis.

## 1. Comprendre — Trois gestes, trois modules

A : les fractions comparent des parts d'une unité. B : les puissances répètent des facteurs. C : les racines carrées retrouvent une longueur non négative à partir d'une aire. Dans chaque module, la première question reste : le calcul est-il défini ? Vous pouvez étudier un module, faire une pause, puis revenir aux deux autres. Gardez le mémo final pour l'examen.

Les trois modules de calcul sont accessibles directement : [A — Fractions](#module-fractions) · [B — Puissances](#module-powers) · [C — Racines et domaine](#module-roots).

## 3. Calculer — Les trois modules, une opération à la fois

<span id="module-fractions"></span>

**A — Fractions (PDF, page 13).**

Dans une fraction $a/b$, le dénominateur ne doit pas être nul : $b\ne0$. L'exemple du PDF s'écrit ligne par ligne :

$$\frac12+\frac13=\frac{1\cdot3}{2\cdot3}+\frac{1\cdot2}{3\cdot2}=\frac36+\frac26=\frac56.$$

Pourquoi multiplier le haut et le bas ? Parce que multiplier par $3/3=1$ ne change pas la valeur. Le résultat $2/5$ est faux : il mélange les tailles de parts.

Une fraction représente une division. Le dénominateur donne la taille des parts ; le numérateur compte ces parts. Pour $b,d\ne0$, les règles sont :

<div className="method-table" tabIndex={0} role="region" aria-label="Mémo des quatre opérations ; tableau défilant">

| Opération | Règle | Exemple avec les étapes |
| --- | --- | --- |
| Addition | $\frac ab+\frac cd=\frac{ad+bc}{bd}$ | $\frac12+\frac13=\frac36+\frac26=\frac56$ |
| Soustraction | $\frac ab-\frac cd=\frac{ad-bc}{bd}$ | $\frac34-\frac16=\frac9{12}-\frac2{12}=\frac7{12}$ |
| Multiplication | $\frac ab\cdot\frac cd=\frac{ac}{bd}$ | $\frac23\cdot\frac35=\frac6{15}=\frac25$ |
| Division, avec $c\ne0$ aussi | $\frac ab\div\frac cd=\frac ab\cdot\frac dc=\frac{ad}{bc}$ | $\frac34\div\frac98=\frac34\cdot\frac89=\frac{24}{36}=\frac23$ |

</div>

**Pour additionner ou soustraire**, rendez les parts de même taille, puis additionnez ou soustrayez leurs nombres. Le dénominateur commun peut être le produit des dénominateurs ; un multiple commun plus petit suffit aussi. On ne calcule jamais une addition en additionnant les dénominateurs.

**Pour multiplier**, aucun dénominateur commun n’est nécessaire. **Pour diviser**, gardez la première fraction et inversez seulement la deuxième, qui doit être non nulle. L’inverse « défait » une multiplication parce que $\frac cd\cdot\frac dc=1$ lorsque $c,d\ne0$.

**Pour finir, simplifiez** en divisant le numérateur et le dénominateur par un même entier non nul : $\frac6{15}=\frac{6\div3}{15\div3}=\frac25$. Un signe au dénominateur peut être remonté au numérateur : $\frac{a}{-b}=-\frac ab$. Une fraction nulle est permise comme nombre ; c’est sa position de diviseur, ou un dénominateur nul, qui rend le calcul interdit.

Vérifiez une division en retrouvant le dividende : $(2/3)(9/8)=3/4$. Cela explique pourquoi on inverse seulement le diviseur.

Autre règle du PDF, page 13 : $\frac{ac}{bc}=\frac ab$ si $b,c\ne0$. On supprime des facteurs communs, jamais des termes d'une somme. Comparez $\frac{2x}{2y}=\frac xy$ pour $y\ne0$ à $\frac{x+2}{y+2}$, où les 2 ne sont pas des facteurs communs.

<span id="module-powers"></span>

**B — Puissances (PDF, page 14).**

Un exposant entier positif compte les facteurs : $a^3=a\cdot a\cdot a$. Pour comprendre les deux nouvelles règles, partons d'une base non nulle :

$$2^0=\frac{2^3}{2^3}=1,\qquad 2^{-3}=\frac{1}{2^3}=\frac18.$$

L'exposant négatif signifie inverse. Par exemple $(-2)^{-3}=-1/8$ mais $(-2)^{-2}=1/4$. Les parenthèses déterminent toujours la base, comme en L21.

Les règles du PDF, pour bases non nulles et exposants entiers m et n :

| Règle | Exemple détaillé |
| --- | --- |
| $a^ma^n=a^{m+n}$ | $2^3\cdot2^2=2^{3+2}=32$ |
| $(a^m)^n=a^{mn}$ | $(2^3)^2=2^3\cdot2^3=2^6=64$ |
| $(ab)^n=a^nb^n$ | $(2\cdot3)^2=2^2\cdot3^2=36$ |
| $a^0=1$ | $7^0=1$ |
| $a^{-n}=1/a^n$ | $2^{-3}=1/8$ |

Pour un exposant entier strictement positif, le produit de bases peut aussi contenir zéro : $(a^2b)^3=a^6b^3$ pour tous réels a et b. On n'utilise pas $0^0$ ni les puissances négatives de zéro. Une puissance ne se distribue pas sur une addition : revoir L22.

<span id="module-roots"></span>

**C — Racines et domaine (PDF, page 14).**

Le PDF définit $\sqrt t$ pour $t\ge0$ comme l'unique réel non négatif dont le carré vaut t. Ne confondez pas le calcul d'une racine et la résolution d'une équation :

| Question | Réponse |
| --- | --- |
| $\sqrt{25}$ | $5$ |
| $z^2=25$ | $z=-5$ ou $z=5$ |
| $\sqrt{-25}$ | Non définie dans les réels |

Pour tout réel x, $\sqrt{x^2}=|x|$. Si x est négatif, son opposé est positif. Exemple : $\sqrt{(-6)^2}=\sqrt{36}=6=|-6|$. La loi du produit $\sqrt{ab}=\sqrt a\sqrt b$ est utilisée pour $a,b\ge0$. Elle permet d'extraire un carré parfait : $\sqrt{72}=\sqrt{36\cdot2}=6\sqrt2$.

Elle ne fonctionne pas avec l'addition : $\sqrt{9+16}=5$ mais $\sqrt9+\sqrt{16}=7$.

**Simplifier sans perdre le domaine.**

Le domaine est l'ensemble des entrées autorisées. Avant de simplifier, noter les conditions de départ.

$$\frac{x^2-9}{x-3}=\frac{(x-3)(x+3)}{x-3}=x+3\quad(x\ne3).$$

À x = 3, l'expression initiale donne 0/0, qui n'est pas défini. Le polynôme simplifié seul vaut 6, mais cette valeur ne doit jamais être réintroduite dans le domaine initial.

| Entrée | $\sqrt x$ | $\sqrt{x^2}$ | $x^{-1}$ | $\frac{x^2-9}{x-3}$ |
| --- | --- | --- | --- | --- |
| −2 | Non défini | 2 | −1/2 | 1 |
| 0 | 0 | 0 | Non défini | 3 |
| 3 | $\sqrt3$ | 3 | 1/3 | Non défini |

## 5. Pratiquer — Trois gestes à combiner

<div className="algebra-exercise">

### 1. Application

Calculer $2/3-1/4$.

<details>
<summary>Indice</summary>

Découpez en douzièmes.

</details>

<details>
<summary>Solution expliquée</summary>

$2/3-1/4=8/12-3/12=5/12$. On soustrait les nombres de parts de même taille.

</details>

</div>


<div className="algebra-exercise">

### 2. Enchaînement

Simplifier $(x^2-4)/(x-2)$ en précisant le domaine.

<details>
<summary>Indice</summary>

Factorisez le numérateur avant de simplifier.

</details>

<details>
<summary>Solution expliquée</summary>

Pour $x\ne2$, $(x^2-4)/(x-2)=(x-2)(x+2)/(x-2)=x+2$. La valeur $2$ reste exclue même si la dernière formule pourrait la recevoir.

</details>

</div>


<div className="algebra-exercise">

### 3. Raisonnement

Pour $x=-3$, comparer $\sqrt{x^2}$, $\sqrt x$ et $x^{-2}$.

<details>
<summary>Indice</summary>

L’ordre « carré puis racine » diffère de « racine directement ».

</details>

<details>
<summary>Solution expliquée</summary>

$\sqrt{x^2}=3$ ; $\sqrt x$ n’est pas définie dans les réels ; $x^{-2}=1/9$. Le signe de l’exposant ne fixe pas le signe du résultat.

</details>

</div>

## 6. Retenir — Fiche de révision à imprimer

<div className="algebra-revision">

- Fractions: $\frac ab\pm\frac cd=\frac{ad\pm bc}{bd}$ ; $\frac ab\cdot\frac cd=\frac{ac}{bd}$ ; $\frac ab\div\frac cd=\frac{ad}{bc}$.
- Conditions : $b,d\ne0$ ; pour la division, aussi $c\ne0$.
- Puissances : bases non nulles, exposants entiers. $a^ma^n=a^{m+n}$ ; $(a^m)^n=a^{mn}$ ; $(ab)^n=a^nb^n$ ; $a^0=1$ ; $a^{-n}=1/a^n$.
- Racines: $\sqrt t\ge0$ si $t\ge0$ ; $\sqrt{x^2}=|x|$ pour tout réel x. $\sqrt{ab}=\sqrt a\sqrt b$ si $a,b\ge0$.
- Domaine avant simplification : dénominateur non nul, radicande non négatif, base non nulle pour une puissance négative. Ne supprimer que des facteurs communs non nuls et conserver les valeurs exclues.

**Auto-évaluation.** Refaire une addition, expliquer l'exposant négatif, distinguer racine et équation, puis noter le domaine d'un quotient avant de le simplifier. Reprendre le module correspondant si une étape reste difficile.

**Pour imprimer:** utilisez la commande Imprimer du navigateur. Les activités montrent un exemple fixe ; indices et solutions sont développés sur papier.
