# Lesson clarity and visual teaching review — 23 October 2026

Review record for [issue #87](https://github.com/GadDev/uni-math-course/issues/87). It records 17 findings and five proposed implementation workstreams; this document does not implement them.

**Baseline:** [main at `5ba78da1277aa91661eaeaece51d7a1fcfd7c525`](https://github.com/GadDev/uni-math-course/commit/5ba78da1277aa91661eaeaece51d7a1fcfd7c525). #86 is closed and its alignment PR #88 is merged, so the final Droites review uses the revised content. This record completes the review and recommendations; implementation remains separate. No lesson, bank, release evidence or repository source file was changed.

## Scope and evidence

- Read all **72 lesson texts**, FR and EN, from the **36 public pairs** selected by `content/releases.json`, starting with L01–L20. Assessed prerequisites, notation, intuition, formal conditions, worked examples, misconception support and checks across each concept’s teaching sequence.
- Compared mathematical expressions across all pairs after normalising whitespace and localized text labels: no expression-sequence differences found. Prose, examples and terminology were also read comparatively; F06 records a specific FR terminology concern.
- Inspected all **85 referenced SVG assets** (39 language pairs and seven shared assets), including labels and surrounding descriptions. Existing truth-assignment trees, Venn hatching, quantifier grids, coordinate/curve plots, residuals and Anscombe plots provide substantial purposeful support. No general replacement or additional-artwork programme is justified.
- Selected banks contain **638 items**. Automated checks found no missing FR/EN prompt, hint, explanation or applicable option/feedback field. Manually inspected the first and last selected item of every bank: **72 items**, both languages, including distractor feedback, plus the targeted items named below. This is representative feedback review, **not independent regrading of all 638 items**.
- Browser evidence uses the current local test build and synthetic authentication fixture, not a hosted learner account. Opened L08/L19/L35/L36 practice in both languages; F01 and F09 describe observations. At 320px, sampled reading pages L03/L15/L29/L33/L35/L36 had no horizontal page overflow. Dense L35 plot legends are small at that size; keyboard-accessible enlargement could be evaluated as polish, but no measured comprehension/accessibility failure is claimed.
- Priorities: **P1** misleading mathematical instruction or lost information needed for understanding; **P2** significant clarity, feedback or sequencing gap; **P3** polish. Evidence is code/text-supported unless explicitly identified as browser-observed; proposed teaching benefits require learner evaluation.
